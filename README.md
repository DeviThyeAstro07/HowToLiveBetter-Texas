# 高性价比人生指南 · 德州版

《高性价比人生指南》美国德州版：213 条按性价比排序的生活决策建议，覆盖健康、急救、法律、医保福利、租房买房、创业、税务等，全部按德州现行规定本地化。

- 每条建议写明**成本 / 说人话 / 收益 / 证据等级 / 来源**，来源只引期刊论文（DOI）与官方文件
- 节内条目按性价比从高到低排列；不用全做，挑一两条即可
