# US Life Guide（德州/阿拉斯加生活指南检索）

## Purpose

用户问及在美国德州或阿拉斯加的生活决策问题时，从两本本地化指南中检索相关条目，按书中的性价比口径和证据等级作答，而不是凭常识编答案。

文档位置：
- 德州版：`~/workspace/your_files/HowToLiveBetter-Texas.md`（213 条）
- 阿拉斯加版：`~/workspace/your_files/HowToLiveBetter-Alaska.md`（235 条）

## Workflow

1. 判断用户问题对应哪个州（德州/阿拉斯加/不确定）。不确定就两个都查（`all`）。
2. 提炼 1–3 个短关键词（口语化，如"被裁 失业金"、"租房 押金"、"熊 喷雾"），运行检索：
   ```
   python3 ~/workspace/skills/us-life-guide/bin/search.py <texas|alaska|all> <关键词1> <关键词2> [--top N]
   ```
   关键词之间是 AND 关系（都必须出现）。第一次没命中就换更短、更口语的词再试。
3. 从命中条目的"说人话"和"收益"组织答案。相关条目之间有互相指路（"见第 X 节第 Y 条"），可顺藤再查。

## Output Contract

- 答案必须注明出处：**第几节第几条 + 条目标题**（如"德州版第 18 节第 3 条"）。
- 引用数字时只用条目里写到的数字，**不自己编数字**；查不到就说查不到。
- 保留条目的证据等级概念：A 级（硬证据/官方法条）优先推荐，C 级说明是常识性建议。
- 法律、福利金额、税率类内容，加一句提醒：政策会变，办事前去官网确认。

## Operating Rules

1. 先检索再回答，不凭记忆编条目编号和数字。
2. 健康类建议可跨州通用（两版数字同源），制度类（医保、劳工、税务、租房）必须用对州的版本。
3. 用户没说州、且问题与州无关（如睡眠、饮食），默认用德州版作答并注明。
4. 检索脚本输出的是条目全文，直接用，不要改写"说人话"里的数字。
